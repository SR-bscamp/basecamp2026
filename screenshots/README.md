# screenshots/ — mock screenshots (Lane C, ticket C3)

Three clearly legible PNGs generated from small HTML or Pillow scripts: (1) VPN "connection failed 809" error, (2) MFA enrollment prompt, (3) timesheet with an invalid booking code. `expected.json` maps each file to its expected screen name and checklist item. They are used by the demo and by the screenshot eval tasks. Fictional UIs only: no real product logos or data.
