# Booking codes

Owner: Finance Operations (timesheets@northwind-advisory.example, ext 4300). Checklist item id: `booking_codes`. Source of truth for exact lookups is the booking-code table below; if a project is not listed, **there is no code for it in this document**. Never guess a code. Ask your engagement manager or Resource Management (staffing@northwind-advisory.example, ext 4400).

## Format
- Internal codes start with `INT-` and are non-billable.
- Client codes start with `CLI-`, then three letters for the client, then a 4-digit number (year 24 plus sequence): for example `CLI-ALD-2401`. They are billable.

## Rules
- Book time to **exactly one** code per timesheet line. Do not split a line across codes.
- Training is INT-TRN-001 unless a client explicitly funds it; then use that client's code and confirm with your engagement manager first.
- New hires with no assignment yet in their first week book onboarding to INT-ADM-001 and any waiting time to INT-BEN-001.
- Time on proposals for a prospective client with no project code yet goes to INT-BD-001.
- Codes are case-sensitive in the timesheet app and must include the hyphens.
- Requests for a new client code take 2 business days; the engagement manager submits it. Analysts cannot request codes.

## FAQ
**Which code do I use for internal training?** INT-TRN-001. It is non-billable. If a client funds the training, use the client's code after your engagement manager confirms.

**Which code do I use when I am between projects?** INT-BEN-001 (bench).

**What code do I use for a project that is not listed?** None. This document has no code for it. Do not invent one. Ask your engagement manager or Resource Management, or open a ticket.

**Is the code for Bluepeak Utilities billable?** Yes: CLI-BLU-2402 is billable.

**Which codes are billable?** Every `CLI-` code. Every `INT-` code is non-billable.

**Can I book half a day to two codes?** Yes, as two separate lines with hours that add up. Each line has one code.

**Who owns a code?** The Owner column shows the team or role that approves hours booked to it.
